## Control overview

Host: `control.<ROOT_DOMAIN>` · Route: `/`

### Purpose and access

Review the platform fleet, headline metrics, recent tenants, and audit activity.

You need an account session and platform access. Platform privileges are separate from tenant roles; privileged writes remain subject to endpoint role checks.

### Screen layout

Fleet Command Center presents platform identity, statistics, commissioned Mahalles, operational links, and Audit Stream.

### Fields and displayed information


This screen has no editable fields or filters in its rendered components.

### Interaction sequence

Open Control Panel → inspect fleet totals → open a tenant command center or platform tool → return to review recent audit entries.

### States and rules

Without PlatformMembership the root displays Platform Root Access Denied. Some health labels are presentation text; do not infer live health from the static Cluster Healthy badge.
