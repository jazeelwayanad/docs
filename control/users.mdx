## User access and accounts

Host: `control.<ROOT_DOMAIN>` · Route: `/users`

### Purpose and access

Manage platform-wide account identities, platform roles, tenant memberships, passwords, status, and sessions.

You need an account session and platform access. Platform privileges are separate from tenant roles; privileged writes remain subject to endpoint role checks.

### Screen layout

The screen has search, role/tenant/status filters, pagination, and selectable rows. Dialogs cover account creation, profile editing, platform role, Mahalle memberships, direct password reset, and single/bulk deletion.

### Fields and displayed information


Displayed table columns: **User**, **Contact**, **Platform Role**, **Mahalle Access & Roles**, **Active Sessions**, **Status**, **Actions**.

### Interaction sequence

Create User → enter identity/password and optional initial access → save. Row actions edit identity, assign/revoke platform access, add/remove tenant membership, reset password with optional session termination, suspend/reactivate, terminate sessions, or delete after confirmation.

### States and rules

Accounts are distinct from tenant citizen members. Destructive and access-changing operations are backend-gated. Reset Password can terminate sessions; profile editing alone does not change credentials.

Explicit validation messages in the rendered forms:

- Password must be at least 8 characters long
- Passwords do not match


The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### പ്രവർത്തനക്രമം

Create User → identity/password, ഐച്ഛിക access നൽകുക → സംരക്ഷിക്കുക. Row actions വഴി identity തിരുത്തൽ, platform access, tenant membership, session termination സഹിതം password reset, suspend/reactivate, session termination, സ്ഥിരീകരിച്ച delete എന്നിവ നടത്താം.

### നിലകളും നിയമങ്ങളും

Accountsഉം citizen membersഉം വേറെയാണ്. Destructive/access-changing പ്രവർത്തനങ്ങൾക്ക് backend അനുമതി വേണം. Reset Password sessions അവസാനിപ്പിക്കാം; profile editing credentials മാറ്റുന്നില്ല.

Rendered formsലെ വ്യക്തമായ validation സന്ദേശങ്ങൾ:

- Password must be at least 8 characters long
- Passwords do not match


Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
