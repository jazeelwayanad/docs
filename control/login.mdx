## Control-panel login

Host: `control.<ROOT_DOMAIN>` · Route: `/login`

### Purpose and access

Authenticate your account before entering the platform control plane.

Entry, public access, and redirect rules are described for this screen below.

### Screen layout

Control Panel Log in displays the shared email/password LoginForm.

### Fields and displayed information


#### Fields and filters: Login form

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Email | `login-email` | email | Yes | you@example.com |
| Password | `login-password` | password | Yes | •••••••• |



### Actions


| Control | Result | Component |
| --- | --- | --- |
| Log in | Submits the associated API change; follow the sequence and failure rules below. | `login-form.tsx` |



### Interaction sequence

Enter credentials → Log in → authenticate → navigate to the control root or a safe return path. Platform membership is checked when platform screens load.

### States and rules

A successful account login does not itself grant platform privileges. Tenant administrator roles are separate from platform membership.

The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

## Control-panel login

Host: `control.<ROOT_DOMAIN>` · Route: `/login`

### ഉദ്ദേശ്യവും പ്രവേശനവും

Platform control panel പ്രവേശനത്തിന് account authenticate ചെയ്യുക.

ഈ സ്ക്രീനിന്റെ entry, public access, redirect നിയമങ്ങൾ താഴെ വിവരിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

Control Panel Log in പൊതുവായ email/password LoginForm കാണിക്കുന്നു.

### ഫീൽഡുകളും പ്രദർശിപ്പിക്കുന്ന വിവരങ്ങളും

### പ്രവർത്തനങ്ങൾ


| നിയന്ത്രണം | ഫലം | Component |
| --- | --- | --- |

### പ്രവർത്തനക്രമം

വിവരങ്ങൾ നൽകുക → Log in → authenticate → control root അല്ലെങ്കിൽ സുരക്ഷിത return path തുറക്കും. Platform സ്ക്രീനുകൾ membership പരിശോധിക്കുന്നു.

### നിലകളും നിയമങ്ങളും

Account login വിജയിച്ചതുകൊണ്ട് platform അധികാരം ലഭിക്കില്ല. Tenant admin roleഉം platform membershipഉം വ്യത്യസ്തമാണ്.

Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
