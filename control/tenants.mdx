## Fleet and Mahalles

Host: `control.<ROOT_DOMAIN>` · Route: `/tenants`

### Purpose and access

Provision and manage tenant records across the platform.

You need an account session and platform access. Platform privileges are separate from tenant roles; privileged writes remain subject to endpoint role checks.

### Screen layout

Fleet & Mahalles includes search, status/district filters, sorting, selection, CSV export, and Provision New Mahalle. Provisioning captures name, slug, optional owner email, geography, Masjid, and contact details.

### Fields and displayed information


Displayed table columns: **Mahalle &amp; Host**, **Location**, **Members / Families**, **Admins**, **Created**, **Status**, **Actions**.

### Interaction sequence

Provision → fill name/slug and optional metadata → save → inspect the new tenant. Select a row for its command center. Suspend/reactivate updates status; bulk delete requires confirmation and reports deleted/skipped results.

### States and rules

Provisioning does not use citizen member intake. Platform role requirements are enforced by the API. Filtering is client-side over loaded tenants; CSV exports the selected/current collection implemented by the handler.

Explicit validation messages in the rendered forms:

- Name and slug are required


The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### പ്രവർത്തനക്രമം

Provision → name/slug, അനുബന്ധ വിവരങ്ങൾ നൽകുക → സംരക്ഷിക്കുക → tenant പരിശോധിക്കുക. വരി command center തുറക്കും. Suspend/reactivate status മാറ്റും; bulk delete സ്ഥിരീകരണവും deleted/skipped ഫലവും നൽകും.

### നിലകളും നിയമങ്ങളും

Provisioning member intake ഉപയോഗിക്കുന്നില്ല. API platform role പരിശോധിക്കുന്നു. ലഭിച്ച tenantsലാണ് client filter; CSV handler നിർവചിച്ച selected/current വിവരങ്ങൾ export ചെയ്യും.

Rendered formsലെ വ്യക്തമായ validation സന്ദേശങ്ങൾ:

- Name and slug are required


Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
