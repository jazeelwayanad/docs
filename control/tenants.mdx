## Manage Mahallu workspaces

Find, provision, and manage Mahallu workspaces across the platform.

### Steps

1. Open **Fleet & Mahalles**. Use search, status and district filters, and sorting to find a workspace.
2. Choose **Provision New Mahalle**. Enter the required name and slug, which forms its address, and optional owner email, geography, Masjid, and contact information.
3. Save and review the new workspace. Open a row for its command center.
4. Use the available suspend or reactivate action to change workspace status.
5. Select records for CSV export or bulk deletion. Confirm deletion and review the deleted and skipped results.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Tenants table

| Field or control | Guidance |
| --- | --- |
| **Search** | Search by name, slug, district, or place… |
| **Status filter** | All statuses, Active only, Suspended only; Default: All |
| **District filter** | All districts; Default: All |
| **Sort by** | Newest first, Oldest first, Name (A-Z), Members (High-Low); Default: newest |
| **Select all rows** | Select or clear this option. |
| **Select Mahallu workspace** | Select or clear this option. |
| **Bulk delete confirm** | Enter bulk delete confirm. |

#### Provision tenant

| Field or control | Guidance |
| --- | --- |
| **Mahalle Name** | Required. e.g. Al-Huda Juma Masjid |
| **Tenant Slug / Domain** | Required. e.g. al-huda |
| **Description (Optional)** | Brief description of this Mahalle jurisdiction... |
| **Assigned Owner Email (Optional)** | admin@example.com |
| **Central Masjid Name** | e.g. Masjidul Huda |
| **State** | Select State; Default: Kerala |
| **District** | Select District |
| **Place / Town** | e.g. Kalpetta |
| **Official Contact Phone** | +919876543210 |
| **Official Contact Email** | contact@alhuda.org |

### Things to know

Filters work on the loaded workspaces. CSV output follows the current or selected records included by the export action. Provisioning creates a workspace rather than registering citizen members. Your platform role may restrict creation, status changes, or deletion.
