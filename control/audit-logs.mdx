## Audit stream

Host: `control.<ROOT_DOMAIN>` · Route: `/audit-logs`

### Purpose and access

Search and inspect platform audit records.

You need an account session and platform access. Platform privileges are separate from tenant roles; privileged writes remain subject to endpoint role checks.

### Screen layout

Audit Logs & Compliance Stream contains search, action-category and tenant filters, a paginated table, JSON export, and an entry-inspection dialog.

### Fields and displayed information


Displayed table columns: **Timestamp**, **Action**, **Actor**, **Mahalle Scope**, **IP Address**, **Payload**.

#### Fields and filters: Audit logs explorer

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Search | `search` | text | Not marked | Search by action, actor email, IP address… |
| Action category | `actionCategory` | select | Not marked | — |
| Selected tenant | `selectedTenant` | select | Not marked | All Mahalles |



### Actions


| Control | Result | Component |
| --- | --- | --- |
| Filter | Invokes the associated handler; see the sequence below. | `audit-logs-explorer.tsx` |
| Export JSON | Downloads the locally generated output. | `audit-logs-explorer.tsx` |
| Inspect | Updates local UI state; persistence is described separately below. | `audit-logs-explorer.tsx` |



### Interaction sequence

Submit search or change a filter → update URL parameters and reset page to 1 → load matching entries. Inspect a row for details. Export JSON downloads the currently loaded entries.

### States and rules

Export covers the current page, not necessarily the full filtered history. The screen has an empty-state message and does not edit, undo, or delete audit records.

## Audit stream

### ഉദ്ദേശ്യവും പ്രവേശനവും

Platform audit രേഖകൾ തിരഞ്ഞ് പരിശോധിക്കുക.

Account sessionഉം platform accessഉം വേണം. Platform privileges tenant rolesൽ നിന്ന് വേറെയാണ്; privileged writes endpoint role checksന് വിധേയമാണ്.

### പ്രവർത്തനക്രമം

Search സമർപ്പിക്കുകയോ filter മാറ്റുകയോ ചെയ്യുക → URL parameters പുതുക്കി page 1 ആക്കും → matching രേഖകൾ വായിക്കും. വരി തുറന്ന് വിവരങ്ങൾ കാണാം. Export JSON ഇപ്പോൾ ലഭിച്ച രേഖകൾ download ചെയ്യും.

### നിലകളും നിയമങ്ങളും

Export നിലവിലെ പേജിനാണ്; മുഴുവൻ filtered history ആവണമെന്നില്ല. ശൂന്യനിലയുണ്ട്; audit തിരുത്തൽ, undo, delete എന്നിവ ഇല്ല.
