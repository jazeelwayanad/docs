Sign in with a platform account that has access to this tool. Your role determines which changes you can make.

## Form templates

Create reusable forms and maintain their versions and assignment.

### Steps

1. Open the form-template page using the application link supplied by your platform team. It is not currently listed in the Control Panel sidebar.
2. Choose **New form** and enter **Name**, **Key**, and an optional category. Select whether the form is platform-wide.
3. Choose **Create form** to save the template and open its detail view.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Create form

| Field or control | Guidance |
| --- | --- |
| **Name** | Required. Marriage NOC Request |
| **Key** | Required. marriage-noc |
| **Category (optional)** | Certificates |
| **Platform-wide form** | Select or clear this option. |

### Things to know

Creating a template does not publish its fields or activate the member dashboard’s request buttons.

## Form template detail

Define a form’s fields, publish a version, and choose which Mahallu workspaces receive it.

### Steps

1. Open a template from the form list. Select its draft version.
2. Add or edit fields using label, key, type, choices, required setting, description, and order.
3. Choose **Publish** and confirm when the version is ready. For later changes, choose **Open new draft version**.
4. In **Assignment**, choose platform-wide availability or select individual Mahallu workspaces, then choose **Save assignment**.
5. To remove the template, choose **Delete form**. You return to the list.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Form field

| Field or control | Guidance |
| --- | --- |
| **Label** | Required. Full name |
| **Key** | Required. Use lowercase letters, numbers, and underscores; for example, full_name. |
| **Type** | Choose text, long text, number, phone, email, date, time, a choice control, file upload, address, or a member, family, or house lookup. |
| **Options** | Enter one choice per line, such as Option A and Option B. |
| **Description (optional)** | Enter description (optional). |
| **Order** | Minimum 0 |
| **Required** | Select or clear this option. |

#### Workspace assignment

| Field or control | Guidance |
| --- | --- |
| **Platform-wide assignment** | Select or clear this option. |
| **Select Mahallu workspace** | Select or clear this option. |

### Things to know

Choice-based fields show **Options**; enter one choice per line. Field type choices describe the template definition and do not activate member-facing submission by themselves. Published versions and drafts are distinct. Publishing fields and saving assignment are separate actions. Published templates are not currently connected to member dashboard application buttons.
