## Zones and divisions

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/divisions`

### Purpose and access

Browse the Mahallu’s configured subdivisions and their household/member counts.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The screen uses the division term configured in Settings. It provides name/code search, division cards or rows, Add family, and a link to configure divisions. Add-family intake can receive a preselected division.

### Interaction sequence

Search for a division → open its detail screen → inspect families or members. To add a household, open Add family and complete its intake. Manage subdivision definitions through structure settings.

### States and rules

The subdivision label is configurable; do not hard-code Ward throughout the product. Division availability depends on the structure setting. The directory does not itself replace the structure editor.

Explicit validation messages in the rendered forms:

- Please provide the Applicant / Househead Name.
- Please provide the primary contact phone number.


The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

പ്രദേശം തിരയുക → വിശദാംശം തുറക്കുക → കുടുംബങ്ങളെയോ അംഗങ്ങളെയോ പരിശോധിക്കുക. കുടുംബം ചേർക്കാൻ Add family intake പൂർത്തിയാക്കുക. പ്രദേശ നിർവചനങ്ങൾ structure settingsൽ പരിപാലിക്കുക.

### നിലകളും നിയമങ്ങളും

പ്രദേശത്തിന്റെ പേര് ക്രമീകരിക്കാവുന്നതാണ്; എല്ലായിടത്തും Ward എന്ന് സ്ഥിരമാക്കരുത്. പ്രദേശങ്ങളുടെ ലഭ്യത structure setting അനുസരിച്ചാണ്. ഡയറക്ടറി structure editorനു പകരമല്ല.

Rendered formsലെ വ്യക്തമായ validation സന്ദേശങ്ങൾ:

- Please provide the Applicant / Househead Name.
- Please provide the primary contact phone number.


Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
