## Collections

Find collections, review receipts, and maintain recorded incoming payments.

### Steps

1. Open **Collections**. Search and filter by operational fund, posting status, category, or collection type.
2. Choose **Record Collection** to open [Record a collection](/admin/record-collection).
3. Open a saved receipt to review it. Use **Print** for printing or saving as PDF, or **WhatsApp** for the available sharing link.
4. Choose **Edit** to update a collection and save the populated form.
5. To remove a collection, confirm its deletion. For several records, select their rows and confirm bulk deletion.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Collections

| Field or control | Guidance |
| --- | --- |
| **Search** | Search payer, receipt #... |
| **Fund filter** | All Operational Funds; Default: All |
| **Posting status filter** | All Statuses, Posted (COA), Unposted (Pending); Default: All |
| **Category filter** | All Categories; Default: All |
| **Type filter** | All Types, Family, Friday, Donation, Hundi Box, Other; Default: All |
| **Select all rows** | Select or clear this option. |
| **Select row** | Select or clear this option. |

### Things to know

Filters apply to the loaded records. Check posting status separately from the receipt: recording a collection does not always mean it has been posted to the ledger.
