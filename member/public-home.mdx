## Public Mahallu homepage

Host: `[tenant].<ROOT_DOMAIN>` · Route: `/`

### Purpose and access

Introduce a Mahallu publicly and provide member login/dashboard access.

Entry, public access, and redirect rules are described for this screen below.

### Screen layout

The page presents Mahallu/Masjid identity, daily prayer cards, Citizen Member Services, announcements, upcoming events, and a member-login call to action. The main link changes when a member session exists.

### Fields and displayed information


This screen has no editable fields or filters in its rendered components.

### Interaction sequence

Visitors choose Member Login (Phone + OTP) → authenticate → open dashboard. Already signed-in members choose Go to Member Dashboard. Announcements and events are displayed from the route’s requests.

### States and rules

Prayer times are fixed page values, not a configured live schedule. Service cards describe offerings without request-submission controls. Failed announcement/event reads fall back to empty lists. Announcement/event reads use operator-JWT-protected endpoints, so anonymous/member-only sessions can receive empty feeds. A public/member feed integration is unfinished.

### പ്രവർത്തനക്രമം

സന്ദർശകർ Member Login (Phone + OTP) → authenticate → dashboard. നേരത്തെ പ്രവേശിച്ചവർ Go to Member Dashboard തിരഞ്ഞെടുക്കാം. അറിയിപ്പുകളും eventsഉം route അഭ്യർത്ഥനകളിൽ നിന്ന് കാണിക്കുന്നു.

### നിലകളും നിയമങ്ങളും

Prayer times സ്ഥിരവിലകളാണ്; ക്രമീകരിച്ച live schedule അല്ല. Service cards സമർപ്പിക്കൽ നിയന്ത്രണങ്ങളില്ലാതെ സേവനങ്ങൾ വിവരിക്കുന്നു. അറിയിപ്പ്/event വായന പരാജയപ്പെട്ടാൽ ശൂന്യ ലിസ്റ്റാകും. അറിയിപ്പ്/event വായന operator-JWT-protected endpoints ഉപയോഗിക്കുന്നു; anonymous/member-only sessionൽ ശൂന്യ feed വരാം. Public/member feed integration പൂർത്തിയായിട്ടില്ല.
