## Member OTP login

Host: `[tenant].<ROOT_DOMAIN>` · Route: `/login`

### Purpose and access

Authenticate a citizen member using the mobile number registered with this Mahallu.

Entry, public access, and redirect rules are described for this screen below.

### Screen layout

Sign In via Phone & OTP shows the phone-entry step, then a six-digit-code step with Verify and log in, resend cooldown, and Use a different number. A link returns to the public homepage.

### Interaction sequence

Enter phone → Send code → request tenant-scoped OTP → enter code → Verify and log in → verify OTP and navigate to the safe destination. Use a different number resets the code step; resend follows its cooldown.

### States and rules

The page recognizes inactivity/expired notices and sanitizes returnTo/redirect. An existing member session redirects to dashboard by default. No SMS provider is wired up: OTP codes are logged server-side for development. Codes expire after five minutes, allow five failed attempts, and are consumed once. The request response does not reveal whether the number is registered.

The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### പ്രവർത്തനക്രമം

Phone → Send code → tenant-scoped OTP ആവശ്യപ്പെടും → code നൽകുക → Verify and log in → OTP പരിശോധിച്ച് സുരക്ഷിത ലക്ഷ്യസ്ഥാനത്തേക്ക് പോകും. Use a different number code step reset ചെയ്യും; resend cooldown അനുസരിച്ചാണ്.

### നിലകളും നിയമങ്ങളും

Inactivity/expired അറിയിപ്പുകളും returnTo/redirect പരിശോധനയും ഉണ്ട്. Member session ഉള്ളവർ default ആയി dashboardലേക്ക് പോകും. SMS provider ബന്ധിപ്പിച്ചിട്ടില്ല: developmentനായി OTP server logൽ എഴുതുന്നു. അഞ്ചു മിനിറ്റിനു ശേഷം expire ചെയ്യും; അഞ്ച് തെറ്റായ ശ്രമങ്ങൾ അനുവദിക്കും; ഒരു തവണ മാത്രം ഉപയോഗിക്കാം. നമ്പർ രജിസ്റ്റർ ചെയ്തിട്ടുണ്ടോ എന്ന് request response വെളിപ്പെടുത്തുന്നില്ല.

Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
