## General and Mahall profile

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/settings`

### Purpose and access

Inspect Mahallu identity, your account, and enabled modules, then open a configuration area.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

General contains Mahallu, Your account, Modules, and Configure sections. Identity shows name, Masjid, Workspace ID, country, and organization; account shows signed-in identity and role; modules are grouped by category.

### Fields and displayed information


This screen has no editable fields or filters in its rendered components.


### Actions


#### Linked navigation

| Link | Target in source |
| --- | --- |
| Change | `/${slug}/settings/structure` |
| View plan | `/${slug}/billing` |



### Interaction sequence

Review identity → use Change for organization → open structure settings. Use View plan for billing; Configure links to structure, finance, notifications, users/roles, and activity.

### States and rules

Identity and account values are read-only here; the page explicitly says they cannot be edited yet. Module availability is controlled by plans/platform administrators. Missing values display Not set.

## General and Mahall profile

### ഉദ്ദേശ്യവും പ്രവേശനവും

മഹല്ലിന്റെ തിരിച്ചറിയൽ, നിങ്ങളുടെ അക്കൗണ്ട്, സജീവ വിഭാഗങ്ങൾ എന്നിവ പരിശോധിച്ച് ക്രമീകരണ വിഭാഗം തുറക്കുക.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

Generalൽ Mahallu, Your account, Modules, Configure വിഭാഗങ്ങളുണ്ട്. പേര്, Masjid, Workspace ID, രാജ്യം, organization; പ്രവേശിച്ച വ്യക്തിയും roleഉം; വിഭാഗം തിരിച്ചുള്ള modules എന്നിവ കാണിക്കുന്നു.
