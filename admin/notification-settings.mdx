## Notification settings

Choose notification preferences and review messaging settings.

### Steps

1. Open **Settings** → **Notifications**.
2. Set the new-service-request and new-dues switches.
3. Enter event-reminder days and the available SMS provider and sender settings.
4. Review the unsaved-changes bar, then save. Use reset to discard unsaved edits.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Notification settings form

| Field or control | Guidance |
| --- | --- |
| **Notify on new service request** | Enter notify on new service request. |
| **Notify on new due** | Enter notify on new due. |
| **Reminder days** | Minimum 0; Maximum 30 |
| **Enable SMS** | Enter enable sms. |
| **SMS provider** | e.g. MSG91 |
| **SMS sender ID** | e.g. MAHALL |

### Things to know

Review any numeric-value errors before saving. Saving an SMS provider name and sender ID does not activate SMS delivery. Member OTP messages are not currently delivered by SMS.
