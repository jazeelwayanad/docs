## Family profile

View a household, its members, dwelling links, and welfare information.

### Steps

1. Open a family from [Families](/family).
2. Review its household details and member roster. Use a reveal control when you need to inspect a hidden identification number.
3. Choose **Add new member** to create a person in this family, or **Add existing member** to select a person already in the directory.
4. Choose **Edit** to update household details and welfare information, then save. **House Name / Family Name** is required.
5. To delete the household, use **Delete Family** in the edit dialog and confirm. You return to the family list.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Edit household details

| Field or control | Guidance |
| --- | --- |
| **Division** | Choose the configured division or area. |
| **Municipal House Number** | e.g. 12/450-A |
| **Mahall house number** | Enter mahall house number. |
| **House Name** | Required. e.g. Baitul Noor, Al Baraka |
| **Head of Family (Applicant / Househead)** | Select head of family |
| **Family category** | Choose an available category. |
| **Primary Contact Phone** | e.g. +91 98765 43210 |
| **Registered Locality / Road** | Street / Place / Locality |
| **Administrative Notes** | Internal administration annotations... |
| **Emergency Contact Person** | Contact person name |
| **Emergency Phone** | e.g. +91 98765 43210 |
| **Requires community support** | Select or clear this option. |
| **Welfare Category** | Select Category, Medical assistance, Regular medicine aid, Financial assistance, Home visit / Elderly care, Mobility assistance, Counselling / Guidance, Children education aid, Other welfare aid |
| **Support Status** | Active Support, Monitoring / Periodic, Resolved / Discontinued; Default: Active |
| **Welfare Notes / Case Summary** | Details regarding family situation, required aid, or monthly allocation... |

### Additional details

The household edit dialog separates house and location information from emergency contacts and welfare. See [Members](/members) for new-member fields and [Families](/family) for household registration.

### Things to know

Choose a member before submitting **Add existing member**. An empty roster means the family has no linked members. **Certificate** currently displays **Coming soon** and does not generate a certificate. A house update can fail while the family update succeeds; check both records after changing dwelling information.
