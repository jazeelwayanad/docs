## Family profile

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/families/[familyId]`

### Purpose and access

Inspect the household, its members, house links, and family-level welfare information.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The detail view shows household information and a member roster. It offers Add new member, Add existing member, Edit, and Certificate controls. Member ID values have reveal controls.

### Fields and displayed information


Displayed table columns: **Members**, **House**, **Ward**, **Address**, **Contact**.

### Interaction sequence

Open a family → Add new member creates a member linked to the household; Add existing member opens an assignment dialog → choose an existing person → save and refresh. Edit opens details/welfare. Deleting through Edit returns to the families registry.

### States and rules

Certificate currently shows Coming soon and generates no household certificate. A household without members shows a dedicated empty message. House-update failures in family editing are treated as non-fatal, so the house and family can become inconsistent.

Explicit validation messages in the rendered forms:

- House Name / Family Name is required.
- Member full name is required.
- Please select a member to add to this family.


The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### നിലകളും നിയമങ്ങളും

Certificate ഇപ്പോൾ Coming soon കാണിക്കുന്നു; സർട്ടിഫിക്കറ്റ് സൃഷ്ടിക്കുന്നില്ല. അംഗങ്ങളില്ലെങ്കിൽ പ്രത്യേക ശൂന്യ സന്ദേശമുണ്ട്. കുടുംബം തിരുത്തുമ്പോൾ വീട്ടിലെ മാറ്റം പരാജയപ്പെട്ടാലും തുടരുന്നതിനാൽ രണ്ടു രേഖകളും പൊരുത്തപ്പെടാതിരിക്കാം.

Rendered formsലെ വ്യക്തമായ validation സന്ദേശങ്ങൾ:

- House Name / Family Name is required.
- Member full name is required.
- Please select a member to add to this family.


Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
