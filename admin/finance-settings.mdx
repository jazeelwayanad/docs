## Finance settings

Configure the funds, ledger accounts, categories, payment methods, and numbering used in finance.

### Steps

1. Open **Settings** → **Finance**. Set the currency and receipt and voucher prefixes, then save those settings.
2. Create the operational funds used to group collections and expenses. Add ledger accounts for accounting where needed.
3. Add or edit bank accounts. Supply the bank name, account title, and account number when creating one.
4. Create collection or expense categories. Choose the operational fund and ledger mapping, then configure target scope, amounts, and recurrence where offered.
5. Configure additional collection fields: choose a field type and label, set choices where applicable, and select whether it is enabled or required. Save the category.
6. Add payment methods with a name, code, and type. Set the reference, cheque, and bank requirements as needed. Save each dialog separately.

### Funds and ledger accounts

<Accordion title="Operational funds">

Choose **Add Operational Fund**, complete the details, and choose **Create Fund**. Use **Edit fund** and **Save Changes** for an existing fund. **Delete fund** opens a confirmation; confirm **Delete Fund** only for the fund you intend to remove.

| Field | Guidance |
| --- | --- |
| **Fund Name** | Required. For example, Masjid Fund or Building Fund. |
| **Fund Code** | Optional short prefix, such as MSJ or BLD. |
| **Description** | Explain the purpose of the fund. |
| Fund color | Choose its identifying color. |
| Default fund | Select whether it should be the default. |

</Accordion>

<Accordion title="Ledger accounts">

Choose **Add Ledger Account** and complete the account details. Use the ledger edit action and **Save Changes** to update an account. The delete action requires confirmation.

| Field | Guidance |
| --- | --- |
| **Fund / Account Name** | Required. Enter the ledger account name. |
| **Fund Code / Abbreviation** | Optional account code. |
| **Type** | Required. Choose income, expense, asset, or liability from the offered choices. |
| **Opening Balance (₹)** | Enter an opening amount when needed. |
| **Description / Purpose (Optional)** | Explain the account’s use. |

You can also maintain accounts through [Chart of accounts](/charts-of-accounts).

</Accordion>

### Numbering and bank details

<Accordion title="Currency and numbering">

Set **Currency**, **Receipt prefix**, and **Voucher prefix**, then choose **Save changes**. All three fields are required.

</Accordion>

<Accordion title="Bank accounts">

Choose **Add Bank Account**, complete the details, and save. Use **Edit bank account** to update an existing account, or **Delete bank account** and confirm to remove it.

| Field | Guidance |
| --- | --- |
| **Bank Name** | Required. Enter the bank name. |
| **Account Title** | Required. Enter the account holder or account title. |
| **Account Number** | Required when creating an account. When editing, leave it blank to keep the existing number. |
| **IFSC Code** | Enter the branch code if applicable. |
| **Branch** | Enter the branch name if applicable. |

</Accordion>

### Collection and expense categories

<Accordion title="Category details">

Choose **Add Collection Category** or **Add Expense Category**. Complete the category details, then choose **Save Category**. Use the edit action to change a category, or the delete action and confirmation to remove it. The fund filter narrows the category list.

| Field | Guidance |
| --- | --- |
| **Operational Fund / Account** | Required. Choose the operational fund. |
| Ledger account | Choose the accounting account. A mapping is needed for posting. |
| **Category Name** | Required. Enter the name shown when recording activity. |
| **Category Code (Optional)** | Enter a short code if needed. |
| **Target Scope** | Choose open/public, family-based, division-based, member-based, or economic-category targeting. The default is family-based. |
| Eligible divisions | Select the divisions when the scope calls for them. |
| **Eligible Economic Category** | Choose BPL, APL, or all categories where applicable. |
| **Default Amount (₹)** | Optional starting amount, zero or greater. |
| **Collection Target (₹)** | Optional target amount, zero or greater. |
| Recurring category | Enable recurrence where applicable. |
| **Recurrence Frequency** | Daily, Weekly, Monthly, Quarterly, Yearly, or Custom. The default is Monthly. |
| Automatic generation | Set the available automatic-generation option. |

</Accordion>

<Accordion title="Additional collection fields">

Use **Fields** to review the category’s form configuration and **Live Preview** to inspect its presentation. Choose a field type, enter a label, and choose **Add Field** to add a custom field. Use the removal control to remove one.

For each field, choose whether it is **Enabled** and **Required**. Edit its label and choice options where offered. Disabled fields are excluded from collection entry. Save the category after changing its fields.

</Accordion>

### Payment methods

<Accordion title="Payment-method details">

Choose **Add Payment Method**, complete the details, then choose **Add Method**. Use the edit action and **Save Changes** to update a method. Use **Deactivate payment method** and confirm to deactivate it.

| Field | Guidance |
| --- | --- |
| **Method Name** | Required. For example, Cash or a named UPI method. |
| **Code** | Required. Enter a short identifying code. |
| **Type** | Required. Cash, Bank Transfer, UPI, Cheque, Online Gateway, or Other. The initial type is Bank Transfer. |
| Require reference | Request a payment reference where needed. |
| Require cheque details | Request cheque information where needed. |
| Require bank account | Request a bank account where needed. |
| Active method | Set availability when editing. |

</Accordion>

### Things to know

An operational fund groups activity; a ledger account records accounting entries. Category ledger mapping affects posting, so a saved collection may still be unposted. When editing a bank account, leave its account-number field blank to keep the existing number. Each settings section or dialog saves independently.
