## House profile

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/houses/[houseId]`

### Purpose and access

Inspect a dwelling and the family and members associated with it.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The page presents House Information, Family, Members, and History panels with an edit-house control.

### Fields and displayed information


#### Fields and filters: House form dialog

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| House number | `house-number` | text | Yes | e.g. 14/A |
| House name | `house-name` | text | Not marked | — |
| Division | `house-division` | select | Not marked | No division |
| Address | `house-address` | text | Not marked | — |
| Notes | `house-notes` | textarea | Not marked | — |



### Actions


| Control | Result | Component |
| --- | --- | --- |
| Edit house | Opens the `open` view. | `edit-house-button.tsx` |
| Cancel | Invokes the associated handler; see the sequence below. | `house-form-dialog.tsx` |
| Save Changes / Add House | Submits the associated API change; follow the sequence and failure rules below. | `house-form-dialog.tsx` |


#### Linked navigation

| Link | Target in source |
| --- | --- |
| ← All houses | `/${slug}/houses` |
| Add one from the Members Directory → | `/${slug}/members` |



### Interaction sequence

Open a house from the directory → inspect its division and address → follow the family/member links → or edit house details and save → refresh.

### States and rules

Missing houses use notFound. Unlinked households and missing members have explicit empty messages. History currently states No history to show yet; do not describe an implemented house timeline.

The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### ഉദ്ദേശ്യവും പ്രവേശനവും

ഒരു വീടും അതുമായി ബന്ധിപ്പിച്ച കുടുംബവും അംഗങ്ങളും പരിശോധിക്കുക.

### പ്രവർത്തനക്രമം

വീട് പട്ടികയിൽ നിന്ന് തുറക്കുക → പ്രദേശവും വിലാസവും പരിശോധിക്കുക → കുടുംബ/അംഗ ലിങ്കുകൾ തുറക്കുക → അല്ലെങ്കിൽ വീട് തിരുത്തി സംരക്ഷിക്കുക → പുതുക്കും.

### നിലകളും നിയമങ്ങളും

വീട് ലഭിക്കാത്തപ്പോൾ notFound ഉപയോഗിക്കുന്നു. കുടുംബമോ അംഗങ്ങളോ ഇല്ലെങ്കിൽ ശൂന്യ സന്ദേശങ്ങളുണ്ട്. History ഇപ്പോൾ No history to show yet ആണ് കാണിക്കുന്നത്; പ്രവർത്തിക്കുന്ന ചരിത്രപട്ടികയായി വിവരിക്കരുത്.

Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
