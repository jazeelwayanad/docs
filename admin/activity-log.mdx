## Activity log

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/settings/activity`

### Purpose and access

Review tenant changes and their actors without editing the audit entries.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The page groups entries by day, showing actor, action description, target context, and time. Pagination loads 30 entries per page.

### Fields and displayed information


This screen has no editable fields or filters in its rendered components.


### Actions


Navigation and row interactions are described in the sequence below.


### Interaction sequence

Open Activity log → inspect newest changes → navigate the page links to older entries.

### States and rules

Denied audit.view and No activity yet have separate states. This is read-only; it does not provide an undo or audit-entry deletion workflow.

## Activity log

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/settings/activity`

### ഉദ്ദേശ്യവും പ്രവേശനവും

മഹല്ലിലെ മാറ്റങ്ങളും അവ നടത്തിയവരെയും audit രേഖ തിരുത്താതെ പരിശോധിക്കുക.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

ദിവസം തിരിച്ചുള്ള രേഖകളിൽ actor, പ്രവർത്തന വിവരണം, ബന്ധപ്പെട്ട വിവരം, സമയം എന്നിവ കാണിക്കുന്നു. ഓരോ പേജിലും 30 രേഖകൾ വായിക്കുന്നു.

### ഫീൽഡുകളും പ്രദർശിപ്പിക്കുന്ന വിവരങ്ങളും


ഈ സ്ക്രീനിന്റെ componentsൽ തിരുത്താവുന്ന ഫീൽഡുകളോ ഫിൽട്ടറുകളോ ഇല്ല.


### പ്രവർത്തനങ്ങൾ


നാവിഗേഷനും വരിയിലെ പ്രവർത്തനങ്ങളും താഴെയുള്ള ക്രമത്തിൽ വിവരിക്കുന്നു.


### പ്രവർത്തനക്രമം

Activity log തുറക്കുക → പുതിയ മാറ്റങ്ങൾ പരിശോധിക്കുക → page ലിങ്കുകളിലൂടെ പഴയവ കാണുക.

### നിലകളും നിയമങ്ങളും

'audit.view' ഇല്ലാത്തതും No activity yetഉം വേറെയാണ്. ഇത് വായിക്കാൻ മാത്രം; undo അല്ലെങ്കിൽ audit-entry deletion workflow ഇല്ല.
