## Events

Create community events and open their registrations and financial summaries.

### Steps

1. Open **Events**. In **Add an event**, enter **Title** and **Starts at**.
2. Add a description and location if needed, then choose **Add Record**.
3. Review the event in the list and open its title to manage registrations.
4. Use the page controls to browse more events. To delete one, choose **Remove** and confirm.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Record details

| Field or control | Guidance |
| --- | --- |
| **Title** | Required. Enter title. |
| **Starts at** | Required. Choose a date and time. |
| **Location** | Enter location. |
| **Description** | Enter additional details. |

### Things to know

Title and start date/time are required. The list shows 20 events per page. An empty first page displays the no-events message.
