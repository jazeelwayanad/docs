## Events

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/events`

### Purpose and access

Maintain events for this Mahallu.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

Add an event form with title, start date-time, description, and location; then Title/Starts/Location table and pagination.

### Interaction sequence

Fill the creation form → submit → refresh the list. Use the row removal control and confirm before deletion. Navigate pages through the page query parameter; events link to their detail screen.

### States and rules

The route loads 20 records per page and provides permission and empty states. Title and Starts at are required. A saved event links to its registrations and finance summary.

The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### പ്രവർത്തനക്രമം

സൃഷ്ടിക്കൽ form പൂർത്തിയാക്കുക → സമർപ്പിക്കുക → പട്ടിക പുതുക്കും. വരിയിലെ നീക്കൽ നിയന്ത്രണം ഉപയോഗിച്ച് സ്ഥിരീകരിക്കുക. page query parameter വഴി പേജുകൾ മാറ്റാം; events വിശദാംശത്തിലേക്ക് ലിങ്കുണ്ട്.

### നിലകളും നിയമങ്ങളും

ഓരോ പേജിലും 20 രേഖകൾ വായിക്കുന്നു; അനുമതി/ശൂന്യ സന്ദേശങ്ങളുണ്ട്. Title, Starts at നിർബന്ധമാണ്. സംരക്ഷിച്ച eventന്റെ registrations, finance summary തുറക്കാം.

Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
