## Announcements

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/announcements`

### Purpose and access

Maintain announcements for this Mahallu.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

Post an announcement form with title, body, audience, and conditional division selector; then Title/Status/Audience table and pagination.

### Fields and displayed information


#### Fields and filters: Page

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Title | `title` | text | Yes | — |
| Body | `body` | textarea | Yes | — |
| Audience | `audience` | select | Not marked | Everyone, Committee only, One division |
| Division | `targetDivisionId` | "select" as const | Not marked | — |



### Actions


| Control | Result | Component |
| --- | --- | --- |
| Add Record | Submits the associated API change; follow the sequence and failure rules below. | `simple-create-form.tsx` |
| Remove | Selects the record for the removal confirmation dialog. | `simple-resource-table.tsx` |
| Remove | Submits the associated API change; follow the sequence and failure rules below. | `simple-resource-table.tsx` |



### Interaction sequence

Fill the creation form → submit → refresh the list. Use the row removal control and confirm before deletion. Navigate pages through the page query parameter; events link to their detail screen.

### States and rules

The route loads 20 records per page and provides permission and empty states. Title and Body are required. Creation sends publish=true. Audience choices are Everyone, Committee only, and One division; One division reveals the division selector.

The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### പ്രവർത്തനക്രമം

സൃഷ്ടിക്കൽ form പൂർത്തിയാക്കുക → സമർപ്പിക്കുക → പട്ടിക പുതുക്കും. വരിയിലെ നീക്കൽ നിയന്ത്രണം ഉപയോഗിച്ച് സ്ഥിരീകരിക്കുക. page query parameter വഴി പേജുകൾ മാറ്റാം; events വിശദാംശത്തിലേക്ക് ലിങ്കുണ്ട്.

### നിലകളും നിയമങ്ങളും

ഓരോ പേജിലും 20 രേഖകൾ വായിക്കുന്നു; അനുമതി/ശൂന്യ സന്ദേശങ്ങളുണ്ട്. Title, Body നിർബന്ധമാണ്. സൃഷ്ടിക്കുമ്പോൾ publish=true അയയ്ക്കുന്നു. Everyone, Committee only, One division തിരഞ്ഞെടുപ്പുകളുണ്ട്; One division തിരഞ്ഞെടുക്കുമ്പോൾ division selector കാണിക്കും.

Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
