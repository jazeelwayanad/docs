## Bulk update

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/accountant/bulk-update`

### Purpose and access

Apply shared changes to selected categories, ledger accounts, or transactions.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

Public Categories, Chart of Accounts, and Transactions tabs each provide search, filters, selection, and target controls. Category changes can alter funds, scope/type, COA mappings, and status; account changes can alter type/parent/fund/status; transactions can move fund/category.

### Fields and displayed information


Displayed table columns: **Public Category Name**, **Inflow / Outflow**, **Assigned Fund**, **Public Scope / Type**, **Chart of Accounts Mapping**, **Status**, **Account Name & Code**, **Account Type**, **Parent Account**, **Document / Ref**, **Party / Member**, **Category**, **Date**, **Amount**.

### Interaction sequence

Select a tab → filter the records → select rows → choose target changes → execute the bulk update → inspect the result and refreshed data. COA mapping can also request posting pending transactions.

### States and rules

Category/account/transaction paths are separate operations. Several updates run record by record, so partial progress is possible. The route loads up to 1000 collections/vouchers; the UI is not a full-dataset guarantee.

### പ്രവർത്തനക്രമം

ടാബ് തിരഞ്ഞെടുക്കുക → ഫിൽട്ടർ ചെയ്യുക → വരികൾ തിരഞ്ഞെടുക്കുക → മാറ്റങ്ങൾ നൽകുക → കൂട്ട പുതുക്കൽ നടത്തുക → ഫലവും പുതുക്കിയ വിവരങ്ങളും പരിശോധിക്കുക. COA mappingൽ pending transactions posting ആവശ്യപ്പെടാം.

### നിലകളും നിയമങ്ങളും

മൂന്നു വിഭാഗങ്ങളും വ്യത്യസ്ത പ്രവർത്തനങ്ങളാണ്. ചില മാറ്റങ്ങൾ ഓരോ രേഖയായി നടക്കുന്നതിനാൽ ഭാഗിക വിജയം ഉണ്ടാകാം. 1000 collections/vouchers വരെ വായിക്കുന്നു; മുഴുവൻ ഡാറ്റയും ലഭിക്കുമെന്ന് ഉറപ്പില്ല.
