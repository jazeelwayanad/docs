## Community reports

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/reports`

### Purpose and access

Choose demographic and community reports from the report hub.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The page displays report links/cards rather than a record-entry form. It links to blood-group, expatriate, and Yatheem reports.

### Fields and displayed information


This screen has no editable fields or filters in its rendered components.


### Actions


Navigation and row interactions are described in the sequence below.


### Interaction sequence

Choose a report → inspect its counts and table → filter the loaded records → return to the report hub to choose another view.

### States and rules

This hub is separate from Finance Reports and Accountant Reports. The destination routes perform their own member-access checks.

### Implementation references

Paths below are relative to the application repository. This is source-reviewed behavior, not a recorded browser test.

- `apps/web/src/app/sites/admin/[tenant]/reports/page.tsx`

Data and access helpers: `apps/web/src/lib/session.ts`, `apps/web/src/lib/server-api.ts`, `apps/web/src/lib/tenants.ts`, `apps/web/src/lib/reports-summary.ts`

## Community reports

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/reports`

### ഉദ്ദേശ്യവും പ്രവേശനവും

റിപ്പോർട്ട് ഹബിൽ നിന്ന് ജനസംഖ്യ/സാമൂഹിക റിപ്പോർട്ടുകൾ തിരഞ്ഞെടുക്കുക.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

രേഖ ചേർക്കാനുള്ള formന് പകരം റിപ്പോർട്ട് ലിങ്കുകൾ/കാർഡുകളാണ്. രക്തഗ്രൂപ്പ്, പ്രവാസി, Yatheem റിപ്പോർട്ടുകളിലേക്ക് ലിങ്കുണ്ട്.

### ഫീൽഡുകളും പ്രദർശിപ്പിക്കുന്ന വിവരങ്ങളും


ഈ സ്ക്രീനിന്റെ componentsൽ തിരുത്താവുന്ന ഫീൽഡുകളോ ഫിൽട്ടറുകളോ ഇല്ല.


### പ്രവർത്തനങ്ങൾ


നാവിഗേഷനും വരിയിലെ പ്രവർത്തനങ്ങളും താഴെയുള്ള ക്രമത്തിൽ വിവരിക്കുന്നു.


### പ്രവർത്തനക്രമം

റിപ്പോർട്ട് തിരഞ്ഞെടുക്കുക → കണക്കുകളും പട്ടികയും പരിശോധിക്കുക → ലഭിച്ച രേഖകളിൽ filter ചെയ്യുക → മറ്റൊരു കാഴ്ചയ്ക്കായി ഹബിലേക്ക് മടങ്ങുക.

### നിലകളും നിയമങ്ങളും

ഇത് Finance Reports, Accountant Reports എന്നിവയിൽ നിന്ന് വേറെയാണ്. ലക്ഷ്യ routeകൾ member പ്രവേശനം പ്രത്യേകം പരിശോധിക്കുന്നു.

### Implementation റഫറൻസുകൾ

താഴെയുള്ള paths application repositoryയെ അടിസ്ഥാനമാക്കിയുള്ളതാണ്. Source പരിശോധിച്ച behavior ആണ്; browser test രേഖയല്ല.

- `apps/web/src/app/sites/admin/[tenant]/reports/page.tsx`

Data/access helpers: `apps/web/src/lib/session.ts`, `apps/web/src/lib/server-api.ts`, `apps/web/src/lib/tenants.ts`, `apps/web/src/lib/reports-summary.ts`
