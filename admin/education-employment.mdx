## Education and employment

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/education-employment`

### Purpose and access

Find education, employment, job-seeker, expatriate, and skill profiles recorded on members.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The screen has summary statistics, search, skill filters, and All Profiles, Job Seekers Desk, Higher Ed & Students, Expatriates / NRIs, and Skills Bank views.

### Interaction sequence

Choose a profile view → search a member, skill, or job → select a skill to narrow Skills Bank → open the linked member profile to edit its underlying information.

### States and rules

The page shows a denied-access panel when the education/employment read is unavailable. Filtering changes the loaded list only. Profile editing belongs to the member dialog; this screen has no separate save form.

### ഉദ്ദേശ്യവും പ്രവേശനവും

അംഗങ്ങളിൽ രേഖപ്പെടുത്തിയ വിദ്യാഭ്യാസം, തൊഴിൽ, ജോലി അന്വേഷിക്കൽ, പ്രവാസം, കഴിവുകൾ എന്നിവ കണ്ടെത്തുക.

### പ്രവർത്തനക്രമം

പ്രൊഫൈൽ കാഴ്ച തിരഞ്ഞെടുക്കുക → അംഗം/കഴിവ്/ജോലി തിരയുക → Skills Bank ചുരുക്കാൻ കഴിവ് തിരഞ്ഞെടുക്കുക → ബന്ധപ്പെട്ട അംഗ പ്രൊഫൈൽ തുറന്ന് വിവരങ്ങൾ തിരുത്തുക.

### നിലകളും നിയമങ്ങളും

വിവരങ്ങൾ വായിക്കാൻ അനുമതിയില്ലെങ്കിൽ പ്രത്യേക സന്ദേശം കാണിക്കും. ഫിൽട്ടർ ലഭിച്ച ലിസ്റ്റിനെ മാത്രമാണ് മാറ്റുന്നത്. തിരുത്തൽ member dialogലാണ്; ഈ സ്ക്രീനിൽ പ്രത്യേക save form ഇല്ല.
