## Health and support

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/health-support`

### Purpose and access

Review confidential member health cases and household welfare needs. The page explicitly identifies health.view as its access requirement.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The register has summary statistics, condition filters, search, and Active Welfare Aid, Chronic Illness & Medicine, Disability Register, Care & Bedridden, and Welfare Households views.

### Interaction sequence

Choose a case category → filter by condition or search → open the linked member or household → edit the underlying health or welfare profile there.

### States and rules

Without health.view the page shows Restricted Access. Member and household lists have separate empty messages. The initial requests load up to 100 records per list; the view does not implement a separate medical case creation form.

### ഉദ്ദേശ്യവും പ്രവേശനവും

രഹസ്യ അംഗ ആരോഗ്യവിവരങ്ങളും കുടുംബ ക്ഷേമാവശ്യങ്ങളും പരിശോധിക്കുക. health.view ആണ് ഈ പേജിലെ വ്യക്തമായ പ്രവേശനാനുമതി.

### പ്രവർത്തനക്രമം

വിഭാഗം തിരഞ്ഞെടുക്കുക → രോഗാവസ്ഥയോ തിരച്ചിലോ ഉപയോഗിക്കുക → ബന്ധപ്പെട്ട അംഗമോ കുടുംബമോ തുറക്കുക → അവിടെയുള്ള ആരോഗ്യ/ക്ഷേമ പ്രൊഫൈൽ തിരുത്തുക.

### നിലകളും നിയമങ്ങളും

health.view ഇല്ലെങ്കിൽ Restricted Access കാണിക്കും. അംഗങ്ങളുടെയും കുടുംബങ്ങളുടെയും ശൂന്യ സന്ദേശങ്ങൾ വ്യത്യസ്തമാണ്. ഓരോ ലിസ്റ്റിലും ആദ്യം 100 രേഖകൾ വരെ വായിക്കുന്നു; പ്രത്യേക മെഡിക്കൽ കേസ് സൃഷ്ടിക്കൽ form ഇല്ല.
