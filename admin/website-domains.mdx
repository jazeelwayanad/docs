## Website domains

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/website/domains`

### Purpose and access

Inspect the displayed subdomain and locally add a custom-domain entry.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

Domains includes a subdomain row, edit modal, and Connect Custom Domain modal with a domain field and CNAME copy instruction.

### Fields and displayed information


#### Fields and filters: Website domains

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Subdomain input | `subdomainInput` | text | Not marked | subdomain |
| Custom domain input | `customDomainInput` | text | Not marked | e.g. www.kambalakkadmosque.com |

### Interaction sequence

Edit subdomain → enter a value → Save updates local rows. Connect Custom Domain → enter domain → optionally copy the displayed CNAME → Save Domain adds a local entry.

### States and rules

These handlers make no backend/DNS requests. Subdomain input is lowercased and stripped to letters, digits, and hyphens. The UI does not provision DNS, validate ownership, or activate a custom domain.

## Website domains

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/website/domains`

### ഉദ്ദേശ്യവും പ്രവേശനവും

കാണിച്ച subdomain പരിശോധിച്ച് custom-domain entry പ്രാദേശികമായി ചേർക്കുക.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

Domainsൽ subdomain വരി, edit modal, domain field/CNAME copy നിർദ്ദേശമുള്ള Connect Custom Domain modal ഉണ്ട്.

### പ്രവർത്തനക്രമം

Subdomain തിരുത്തുക → മൂല്യം നൽകുക → Save local വരി മാറ്റും. Connect Custom Domain → domain നൽകുക → ആവശ്യമായാൽ CNAME copy ചെയ്യുക → Save Domain local entry ചേർക്കും.

### നിലകളും നിയമങ്ങളും

Backend/DNS അഭ്യർത്ഥനകളില്ല. Subdomain lowercase ആക്കി അക്ഷരം, സംഖ്യ, hyphen മാത്രം നിലനിർത്തുന്നു. DNS സൃഷ്ടിക്കലോ ഉടമസ്ഥത പരിശോധിക്കലോ custom domain സജീവമാക്കലോ UI ചെയ്യുന്നില്ല.
