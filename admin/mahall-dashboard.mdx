## Mahall dashboard

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/overview`

### Purpose and access

Review the operational dashboard inside the Mahall navigation area. This is a separate screen from Home.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The page starts with a greeting and setup checklist. It then presents recent members, the treasury snapshot, upcoming agenda, and demographic summaries.

### Fields and displayed information


This screen has no editable fields or filters in its rendered components.

### Interaction sequence

Check setup progress → follow a checklist link to the relevant settings page → return to inspect recent records → open a member or event from its link.

### States and rules

Recent-member and event panels distinguish unavailable data from an empty list. Supporting requests may return null; do not infer record creation or deletion from dashboard fallback values.

## Mahall dashboard

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/overview`

### ഉദ്ദേശ്യവും പ്രവേശനവും

Mahall നാവിഗേഷനിലുള്ള പ്രവർത്തന ഡാഷ്ബോർഡ് പരിശോധിക്കുക. ഇത് Home സ്ക്രീനിൽ നിന്ന് വ്യത്യസ്തമാണ്.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

സ്വാഗത സന്ദേശവും സജ്ജീകരണ പട്ടികയും ആദ്യം വരുന്നു. തുടർന്ന് പുതിയ അംഗങ്ങൾ, ധനകാര്യ സംഗ്രഹം, വരാനിരിക്കുന്ന പരിപാടികൾ, ജനസംഖ്യാ സംഗ്രഹങ്ങൾ എന്നിവ കാണിക്കുന്നു.

### ഫീൽഡുകളും പ്രദർശിപ്പിക്കുന്ന വിവരങ്ങളും

### പ്രവർത്തനക്രമം

സജ്ജീകരണ പുരോഗതി പരിശോധിക്കുക → അനുയോജ്യമായ ക്രമീകരണ ലിങ്ക് തുറക്കുക → തിരിച്ചെത്തി പുതിയ രേഖകൾ പരിശോധിക്കുക → അംഗത്തിന്റെയോ പരിപാടിയുടെയോ ലിങ്ക് തുറക്കുക.

### നിലകളും നിയമങ്ങളും

അംഗങ്ങളുടെയും പരിപാടികളുടെയും വിഭാഗങ്ങൾ വിവരങ്ങൾ ലഭ്യമല്ലാത്തതും രേഖകൾ ഇല്ലാത്തതും വേർതിരിക്കുന്നു. null ലഭിക്കുന്ന കണക്കുകളിൽ നിന്ന് രേഖകൾ ചേർത്തതോ നീക്കിയതോ അനുമാനിക്കരുത്.
