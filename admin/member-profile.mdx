## Member profile

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/members/[memberId]`

### Purpose and access

Inspect one member and open the same member-edit dialog used by the directory.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The record view groups identity and contact details, household links, education/work, health/support, and residency information. The identification number has a reveal control. A missing household offers Link a family.

### Fields and displayed information


Displayed table columns: **Age**, **Phone**, **Email**, **Household**.

### Interaction sequence

Open a member row → inspect the profile → use Edit member or Link a family → update the dialog → save → refresh the profile. Use household links to navigate to related records.

### States and rules

The route resolves the member by ID within the tenant and uses notFound when the record cannot be loaded. No health details recorded is a dedicated empty panel. Revealing the ID changes visibility only.

Explicit validation messages in the rendered forms:

- Member full name is required.


The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### ഉദ്ദേശ്യവും പ്രവേശനവും

ഒരംഗത്തിന്റെ വിവരങ്ങൾ പരിശോധിച്ച് ഡയറക്ടറിയിലുള്ള അതേ തിരുത്തൽ ഡയലോഗ് തുറക്കുക.

### സ്ക്രീൻ ക്രമം

### പ്രവർത്തനക്രമം

അംഗത്തിന്റെ വരി തുറക്കുക → വിവരങ്ങൾ പരിശോധിക്കുക → Edit member അല്ലെങ്കിൽ Link a family തിരഞ്ഞെടുക്കുക → ഡയലോഗിൽ മാറ്റം നൽകുക → സംരക്ഷിക്കുക → പ്രൊഫൈൽ പുതുക്കും. കുടുംബ ലിങ്കിലൂടെ ബന്ധപ്പെട്ട രേഖ തുറക്കാം.

### നിലകളും നിയമങ്ങളും

അംഗത്തെ മഹല്ലിനുള്ളിലെ ID ഉപയോഗിച്ചാണ് വായിക്കുന്നത്; ലഭിക്കാത്തപ്പോൾ notFound ഉപയോഗിക്കുന്നു. ആരോഗ്യവിവരങ്ങൾ ഇല്ലെങ്കിൽ പ്രത്യേക ശൂന്യ സന്ദേശം കാണിക്കുന്നു. ID വെളിപ്പെടുത്തുന്നത് പ്രദർശനം മാത്രമാണ് മാറ്റുന്നത്.

Rendered formsലെ വ്യക്തമായ validation സന്ദേശങ്ങൾ:

- Member full name is required.


Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
