## Taxes and legal tracker

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/accountant/taxes-legal`

### Purpose and access

Track statutory filing obligations and mark filings completed. This is a tracker, not an external tax-submission integration.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The page lists filing records. Add Statutory Compliance opens title, filing type, due date, period, amount, and notes.

### Fields and displayed information


Displayed table columns: **Filing / Obligation**, **Type**, **Period**, **Due Date**, **Statutory Fees**, **Status**, **Actions**.

#### Fields and filters: Taxes legal client

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Filing Title | `title` | text | Yes | Enter filing title |
| Type | `filingType` | text | Yes | — |
| Due Date | `dueDate` | date | Yes | — |
| Period | `period` | text | Not marked | Enter period |
| Filing Fees / Tax (₹) | `amount` | number | Not marked | 0.00 |
| Notes / Reference | `notes` | textarea | Not marked | Registration number, acknowledgment details... |



### Actions


| Control | Result | Component |
| --- | --- | --- |
| Add Statutory Compliance | Opens the `modal` view. | `taxes-legal-client.tsx` |
| Mark Filed | Submits the associated API change; follow the sequence and failure rules below. | `taxes-legal-client.tsx` |
| Cancel | Closes or clears the `modal` view/selection. | `taxes-legal-client.tsx` |
| Saving... / Save Record | Submits the associated API change; follow the sequence and failure rules below. | `taxes-legal-client.tsx` |



### Interaction sequence

Add a filing → enter title and due date plus optional tracking details → save → use Mark Filed on a record to change its status to FILED and record the current payment date.

### States and rules

Title and due date are required by the handler. Mark Filed updates the local application record; it does not submit documents to a government portal.

### ഉദ്ദേശ്യവും പ്രവേശനവും

നിയമപരമായ filing ബാധ്യതകൾ രേഖപ്പെടുത്തി പൂർത്തിയായതായി അടയാളപ്പെടുത്തുക. ഇത് tracking ആണ്; പുറത്തുള്ള tax portalലേക്കുള്ള integration അല്ല.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

### പ്രവർത്തനക്രമം

Filing ചേർക്കുക → title, due date, അനുബന്ധ വിവരങ്ങൾ നൽകുക → സംരക്ഷിക്കുക → Mark Filed ഉപയോഗിച്ച് FILED ആക്കുകയും നിലവിലെ payment date രേഖപ്പെടുത്തുകയും ചെയ്യുക.

### നിലകളും നിയമങ്ങളും

Title, due date handlerൽ നിർബന്ധമാണ്. Mark Filed ആപ്പിലെ രേഖ മാത്രം പുതുക്കുന്നു; സർക്കാർ പോർട്ടലിലേക്ക് രേഖ സമർപ്പിക്കുന്നില്ല.
