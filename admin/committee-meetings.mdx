## Meetings and minutes

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/committee/meetings`

### Purpose and access

Schedule committee meetings and record decisions within a selected meeting.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The page shows a meeting list and selected-meeting details, with Schedule meeting, Edit, Remove, and the decision form.

### Interaction sequence

Schedule meeting → enter its details → save → select the meeting → add a decision or minute → save → refresh. Editing and deletion apply to the selected meeting.

### States and rules

Empty meetings have a dedicated state. Meeting and decision saves are separate requests; adding a meeting does not automatically create its decisions.

The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### ഉദ്ദേശ്യവും പ്രവേശനവും

കമ്മിറ്റി യോഗങ്ങൾ നിശ്ചയിച്ച് തിരഞ്ഞെടുത്ത യോഗത്തിൽ തീരുമാനങ്ങൾ രേഖപ്പെടുത്തുക.

### പ്രവർത്തനക്രമം

Schedule meeting → വിവരങ്ങൾ നൽകുക → സംരക്ഷിക്കുക → യോഗം തിരഞ്ഞെടുക്കുക → തീരുമാനം/minute ചേർക്കുക → സംരക്ഷിക്കുക → പുതുക്കും. തിരുത്തലും നീക്കലും തിരഞ്ഞെടുത്ത യോഗത്തിനാണ്.

### നിലകളും നിയമങ്ങളും

യോഗങ്ങളില്ലെങ്കിൽ പ്രത്യേക സന്ദേശമുണ്ട്. യോഗവും തീരുമാനവും വ്യത്യസ്ത അഭ്യർത്ഥനകളിൽ സംരക്ഷിക്കുന്നു; യോഗം ചേർത്താൽ തീരുമാനങ്ങൾ സ്വയം സൃഷ്ടിക്കില്ല.

Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
