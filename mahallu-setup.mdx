## Mahallu setup wizard

### Purpose and access

Create a Mahallu and its initial administrator through the guided setup.

Entry, public access, and redirect rules are described for this screen below.

### Screen layout

Mahallu Details collects name and location; Administrator Account collects identity/password for new users; completion shows the created Mahallu URL and dashboard action. Existing users reuse their account.

### Fields and displayed information

#### Mahallu details step

| Field / control | Input | Required marker |
| --- | --- | --- |
| Mahallu Name | text | Yes |

| Field / control | Input | Required marker |
| --- | --- | --- |
| Location search input | text | Not marked |

#### Admin account step

| Field / control | Input | Required marker |
| --- | --- | --- |
| Administrator Name | text | Yes |
| Email Address | email | Yes |
| Onboarding password | password | Yes |
| Confirm Password | password | Yes |

#### Interaction sequence

Enter Mahallu name/location → Next → complete account details → Complete Setup & Create Mahallu → register if needed, then create tenant → completion → open admin dashboard. URL conflicts retry once with a numeric suffix.
