## Chart of accounts

Create and maintain ledger accounts used for accounting and financial reports.

### Steps

1. Open **Accountant** → **Chart of accounts**.
2. Choose **New Account**, enter the account name, and select its type. Add a code and description if needed.
3. Choose **Save Account**. A successful save closes the dialog and refreshes the list.
4. Search by name, code, description, or parent name. Filter by account type or **System Accounts**.
5. Open an account name or choose **Edit account details**. Update its name, code, description, or available details, then choose **Update Account**.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Accounts

| Field or control | Guidance |
| --- | --- |
| **Account filter** | All Accounts , Assets , Liabilities , Equity , Income , Expenses , System Accounts ; Default: All |
| **Search** | Search by name or code... |
| **Account Name** | Required. e.g., Cash in Hand, Hundi Collection... |
| **Account Code** | e.g., 1010, 2010... |
| **Account Type** | Required. ASSET, LIABILITY, EQUITY, INCOME, EXPENSE; Default: ASSET |
| **Parent Account (Optional)** | None (Top Level Account) |
| **Description** | Account purpose or notes... |

### Things to know

An account name is required. Parent-account assignment currently fails when saving through this screen; save without a parent. Editing does not change the account type. This page has no account-deletion action.
