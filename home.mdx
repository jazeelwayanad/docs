## Home dashboard

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]`

### Purpose and access

Use this landing screen to review your Mahallu and open its main work areas.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The screen composes DashboardHero, DashboardMetrics, DashboardModules, DashboardChart, and DashboardMilestones, followed by the website card. It displays tenant identity, aggregate measures, module shortcuts, charts, and setup milestones.

### Interaction sequence

Open your Mahallu from the admin entry point → review the headline measures → choose a module shortcut → continue in that module. The website card links to the public site and website management.

### States and rules

The page catches failures in several supporting reads and falls back to null data or empty lists. Treat unavailable dashboard measures as missing data rather than verified zero activity.

## Home dashboard

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]`

### ഉദ്ദേശ്യവും പ്രവേശനവും

നിങ്ങളുടെ മഹല്ലിന്റെ സ്ഥിതി പരിശോധിക്കാനും പ്രധാന പ്രവർത്തന വിഭാഗങ്ങൾ തുറക്കാനും ഈ ഹോം സ്ക്രീൻ ഉപയോഗിക്കുക.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

### സ്ക്രീൻ ക്രമം

DashboardHero, DashboardMetrics, DashboardModules, DashboardChart, DashboardMilestones എന്നിവയ്ക്കു ശേഷം വെബ്സൈറ്റ് കാർഡ് വരുന്നു. മഹല്ലിന്റെ പേര്, സംഗ്രഹ കണക്കുകൾ, വിഭാഗങ്ങളിലേക്കുള്ള ലിങ്കുകൾ, ചാർട്ടുകൾ, സജ്ജീകരണ പുരോഗതി എന്നിവ കാണിക്കുന്നു.

### പ്രവർത്തനക്രമം

അഡ്മിൻ പ്രവേശനത്തിൽ നിന്ന് മഹല്ല് തുറക്കുക → പ്രധാന കണക്കുകൾ പരിശോധിക്കുക → ആവശ്യമായ വിഭാഗം തിരഞ്ഞെടുക്കുക → അവിടെ പ്രവർത്തനം തുടരുക. വെബ്സൈറ്റ് കാർഡിലൂടെ പൊതു സൈറ്റും വെബ്സൈറ്റ് മാനേജ്മെന്റും തുറക്കാം.

### നിലകളും നിയമങ്ങളും

ചില അനുബന്ധ വിവരങ്ങൾ ലഭിക്കാത്തപ്പോൾ null അല്ലെങ്കിൽ ശൂന്യ ലിസ്റ്റ് ഉപയോഗിക്കുന്നു. ലഭ്യമല്ലാത്ത കണക്കുകളെ പ്രവർത്തനം ഇല്ലെന്ന സ്ഥിരീകരണമായി കാണരുത്.
