## Billing plan

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/billing`

### Purpose and access

Inspect the tenant billing-plan presentation.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

Billing shows a fixed Community Basic/ACTIVE plan, renewal text, Plan Limits, and an Upgrade Subscription Plan modal with Growth Mahall and Juma Enterprise options.

### Fields and displayed information


This screen has no editable fields or filters in its rendered components.


### Actions


| Control | Result | Component |
| --- | --- | --- |
| Refresh | Updates local UI state; persistence is described separately below. | `billing-plan-details.tsx` |
| Upgrade | Opens the `upgrade modal` view. | `billing-plan-details.tsx` |
| Cancel | Closes or clears the `upgrade modal` view/selection. | `billing-plan-details.tsx` |
| Confirm Upgrade | Updates local UI state; persistence is described separately below. | `billing-plan-details.tsx` |



### Interaction sequence

Upgrade → select a tier → Confirm Upgrade → a local success state appears and the modal closes after a timer.

### States and rules

Plan labels, limits, prices, and renewal date are fixed display values. Upgrade/Refresh make no billing API calls; this does not change the persisted subscription.

### Implementation references

Paths below are relative to the application repository. This is source-reviewed behavior, not a recorded browser test.

- `apps/web/src/app/sites/admin/[tenant]/billing/page.tsx`

Data and access helpers: `apps/web/src/lib/session.ts`, `apps/web/src/lib/server-api.ts`, `apps/web/src/lib/tenants.ts`

### ഉദ്ദേശ്യവും പ്രവേശനവും

Tenant billing plan കാഴ്ച പരിശോധിക്കുക.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.
