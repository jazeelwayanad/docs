## Payments

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/finance/payments`

### Purpose and access

Record and manage paid expense vouchers, including category, fund, ledger, and bank allocation.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The page has payee/voucher/description search, fund, posting-status, expense-account, and category filters. The table offers edit and delete. Record Expense opens category, payee, amount, method, optional bank account, date, and description fields.

### Fields and displayed information


Displayed table columns: **Date**, **Voucher #**, **Payee / Party**, **Expense Head / Fund**, **Status**, **Payment Mode**, **Amount**, **Actions**.

### Interaction sequence

Record Expense → choose expense category → enter payee, amount, payment method, and date → select bank account where applicable → submit. The request creates a PAYMENT/EXPENSE voucher marked PAID. Edit updates the voucher; deletion uses individual or bulk confirmation.

### States and rules

Required controls include payee, amount, and date. The selected category supplies fund/account mapping. API errors show destructive notifications. These records represent paid expenses; the UI does not run a separate approval journey before this creation request.

### പ്രവർത്തനക്രമം

Record Expense → ചെലവ് വിഭാഗം തിരഞ്ഞെടുക്കുക → payee, തുക, രീതി, തീയതി നൽകുക → ആവശ്യമെങ്കിൽ ബാങ്ക് തിരഞ്ഞെടുക്കുക → സമർപ്പിക്കുക. PAYMENT/EXPENSE വൗച്ചർ PAID ആയി സൃഷ്ടിക്കുന്നു. Edit പുതുക്കും; വ്യക്തിഗത/കൂട്ട നീക്കലിന് സ്ഥിരീകരണം ഉണ്ട്.

### നിലകളും നിയമങ്ങളും

payee, തുക, തീയതി നിർബന്ധ നിയന്ത്രണങ്ങളാണ്. തിരഞ്ഞെടുത്ത വിഭാഗത്തിൽ നിന്ന് ഫണ്ട്/അക്കൗണ്ട് ലഭിക്കുന്നു. API പിശകുകൾ അറിയിപ്പായി കാണിക്കും. ഇവ നൽകിയ ചെലവുകളാണ്; സൃഷ്ടിക്കലിന് മുമ്പുള്ള പ്രത്യേകം approval journey ഈ UI നടത്തുന്നില്ല.
