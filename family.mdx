## Families registry

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/families`

### Purpose and access

Maintain households and connect their house, head, members, categories, and welfare details.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The registry has filter pills, search, house filter, sorting, selectable rows, page-size controls, and bulk actions. New-family intake uses location, applicant, and members steps. Editing uses details and welfare tabs.

### Interaction sequence

Choose Add family → enter location/house information → supply the applicant or househead and primary phone → add household members → submit. The client creates the house when needed, then the family, head, and additional members; success opens the new family profile. Use Edit to change the saved household.

### States and rules

Applicant/househead name and primary phone are required by the intake handler. Multi-request creation is not atomic; a late failure can leave earlier records saved. The registry initially loads 100 families. Bulk removal and bulk house assignment only show success and refresh; neither persists the requested change. Import and summary-report menu actions are notification-only.

Explicit validation messages in the rendered forms:

- House Name / Family Name is required.
- Please provide the Applicant / Househead Name.
- Please provide the primary contact phone number.


The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### പ്രവർത്തനക്രമം

Add family തിരഞ്ഞെടുക്കുക → സ്ഥലവും വീടും നൽകുക → അപേക്ഷകന്റെ/കുടുംബനാഥന്റെ പേരും പ്രധാന ഫോണും നൽകുക → മറ്റു അംഗങ്ങളെ ചേർക്കുക → സമർപ്പിക്കുക. ആവശ്യമായാൽ വീട് സൃഷ്ടിച്ച ശേഷം കുടുംബം, കുടുംബനാഥൻ, മറ്റു അംഗങ്ങൾ എന്നിവ സൃഷ്ടിക്കുന്നു. വിജയിക്കുമ്പോൾ പുതിയ കുടുംബ പ്രൊഫൈൽ തുറക്കും. Edit വഴി തിരുത്താം.

### നിലകളും നിയമങ്ങളും

അപേക്ഷകന്റെ/കുടുംബനാഥന്റെ പേരും പ്രധാന ഫോണും നിർബന്ധമാണ്. പല അഭ്യർത്ഥനകളിലൂടെയുള്ള സൃഷ്ടിക്കൽ ഒരൊറ്റ ഇടപാടല്ല; അവസാന ഘട്ടം പരാജയപ്പെട്ടാലും മുൻ രേഖകൾ നിലനിൽക്കാം. ആദ്യം 100 കുടുംബങ്ങൾ വായിക്കുന്നു. കൂട്ട നീക്കലും കൂട്ട house assignmentഉം വിജയസന്ദേശവും പുതുക്കലും മാത്രം നടത്തുന്നു; ആവശ്യപ്പെട്ട മാറ്റം സംരക്ഷിക്കുന്നില്ല. Import, summary-report നിയന്ത്രണങ്ങൾ അറിയിപ്പുകൾ മാത്രമാണ്.

Rendered formsലെ വ്യക്തമായ validation സന്ദേശങ്ങൾ:

- House Name / Family Name is required.
- Please provide the Applicant / Househead Name.
- Please provide the primary contact phone number.


Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
