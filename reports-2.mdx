## Balance sheet

Review assets, liabilities, equity, and totals.

### Steps

1. Open the report from the accounting area.
2. Check its heading and the information shown for the period.
3. Review the account rows, movements, and totals appropriate to this report.
4. Open the underlying finance or ledger records when you need to investigate a figure.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Report controls

| Field or control | Guidance |
| --- | --- |
| **Date filter** | Today, This Week, This Month, This Quarter, This Fiscal Year, Previous Fiscal Year |
| **Report basis** | Accrual, Cash Basis |
| **Collapse sub accounts** | Select or clear this option. |
| **Compare with** | None, Previous Period, Previous Year; Default: None |

### Things to know

Date and accounting-basis controls currently change only what the viewer displays; they do not reliably change the report data. **Run Report** reloads the view. Use the available export menu to save or print the loaded rows; report scheduling and options are unavailable. Confirm the actual reporting period and underlying records before relying on totals.

## Accounting reports catalog

Find financial reports and keep shortcuts to the ones you use most often.

### Steps

1. Open **Reports** in the finance or accounting area.
2. Search for a report or select a category.
3. Choose **View** or **Open** to display the selected report, then review its rows and totals.
4. Use the star control to add a report to **Quick Favorites**. Close the report to return to the catalog.

### Fields and choices

Complete the required fields and any additional details requested for your selections.

#### Reports center

| Field or control | Guidance |
| --- | --- |
| **Search** | Search reports by name or description... |

#### Report controls

| Field or control | Guidance |
| --- | --- |
| **Date filter** | Today, This Week, This Month, This Quarter, This Fiscal Year, Previous Fiscal Year |
| **Report basis** | Accrual, Cash Basis |
| **Collapse sub accounts** | Select or clear this option. |
| **Compare with** | None, Previous Period, Previous Year; Default: None |

### Things to know

Favorites are saved in your current browser for this Mahallu. Some catalog reports use estimates or fixed example values. Date and basis controls do not reliably filter the underlying figures, and report scheduling and options are unavailable. Confirm source records before using a report for accounting decisions.

### Save or print a report

Open **Export** in the report viewer and choose **Export as PDF** or **Print Report** to use the browser print dialog. Choose a PDF destination to save a copy. **Export as CSV** downloads the current report rows. **Export as XLSX (Excel)** downloads an Excel-compatible file with an .xls extension.

Exports use the report’s currently loaded rows. Changing a displayed date or basis does not establish that the exported figures have been recalculated. **Report Options** and **Schedule Report** are not connected.
