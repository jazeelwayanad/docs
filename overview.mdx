## Finance overview

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/finance`

### Purpose and access

Review cash/bank balances, collection activity, expenses, and outstanding dues before opening finance workflows.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The dashboard presents cash balance, bank balances, a six-month income/expense chart, Recent Collections, and Pending Dues & Arrears.

### Fields and displayed information


Displayed table columns: **Date**, **Payer / Family**, **Category**, **Amount**, **Member / Family**, **Particulars**, **Due Date**.

### Interaction sequence

Inspect the balances and trend → open collection or payment links to record transactions → return to review refreshed summaries.

### States and rules

Unavailable finance access produces a permission panel. Supporting panels use their own fallbacks. A balance card is a summary, not a bank-reconciliation or payment control.

### ഉദ്ദേശ്യവും പ്രവേശനവും

ധനകാര്യ പ്രവർത്തനങ്ങൾ തുടങ്ങുന്നതിന് മുമ്പ് പണം/ബാങ്ക് ബാലൻസ്, വരവ്, ചെലവ്, കുടിശ്ശിക എന്നിവ പരിശോധിക്കുക.

### പ്രവർത്തനക്രമം

ബാലൻസും പ്രവണതയും പരിശോധിക്കുക → വരവോ ചെലവോ രേഖപ്പെടുത്താൻ ബന്ധപ്പെട്ട ലിങ്ക് തുറക്കുക → പുതുക്കിയ സംഗ്രഹം കാണാൻ മടങ്ങുക.

### നിലകളും നിയമങ്ങളും

ധനകാര്യ പ്രവേശനം ലഭ്യമല്ലെങ്കിൽ അനുമതി സന്ദേശമുണ്ട്. അനുബന്ധ വിഭാഗങ്ങൾക്ക് പ്രത്യേകം fallback ഉണ്ട്. ബാലൻസ് കാർഡ് സംഗ്രഹമാണ്; ബാങ്ക് പൊരുത്തപ്പെടുത്തലോ പണം നൽകലോ നടത്തുന്ന നിയന്ത്രണമല്ല.
