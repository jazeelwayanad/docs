## Create Mahalle

Host: `<ROOT_DOMAIN>` · Route: `/new-mahalle`

### Purpose and access

Create a tenant from the marketing-host form using an authenticated account.

Entry, public access, and redirect rules are described for this screen below.

### Screen layout

Create your Mahalle contains the CreateTenantForm with tenant name and slug/URL. The slug field supports automatic name-based generation, manual editing, and availability checking.

### Fields and displayed information


#### Fields and filters: Create tenant form

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Mahalle name | `tenant-name` | text | Yes | Al Noor Mahalle |


#### Fields and filters: Slug field

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Id | `id` | text | Yes | your-mahalle |



### Actions


| Control | Result | Component |
| --- | --- | --- |
| Create Mahalle | Submits the associated API change; follow the sequence and failure rules below. | `create-tenant-form.tsx` |



### Interaction sequence

Enter tenant identity → submit → create through /tenants → continue to the resulting administrator workspace.

### States and rules

The route requires an account session; unauthenticated visitors are redirected. This simpler creation form is separate from the location/account onboarding wizard.

The rendered action controls bind loading indicators to pending state. Failed API saves keep their documented error/notification path; a loading indicator alone does not establish persistence.

### ഉദ്ദേശ്യവും പ്രവേശനവും

### പ്രവർത്തനക്രമം

Tenant identity നൽകുക → സമർപ്പിക്കുക → /tenants വഴി സൃഷ്ടിക്കും → അഡ്മിൻ workspaceൽ തുടരുക.

### നിലകളും നിയമങ്ങളും

Routeന് account session വേണം; പ്രവേശിക്കാത്തവർ redirect ചെയ്യും. ഇത് location/account onboarding wizardൽ നിന്ന് വ്യത്യസ്തമായ ലളിത form ആണ്.

Rendered action controls pending state അനുസരിച്ച് loading indicator കാണിക്കുന്നു. API save പരാജയപ്പെട്ടാൽ ബന്ധപ്പെട്ട error/notification കാണിക്കും; loading indicator മാത്രം persistence തെളിയിക്കുന്നില്ല.
