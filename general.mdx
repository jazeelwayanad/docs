## Website overview

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/website`

### Purpose and access

Review website status and the public-site link.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The screen shows the public URL, website status, password protection, View website, and Launch controls.

### Fields and displayed information


#### Fields and filters: Website overview

| Field / control | Reference | Input | Required marker | Choices / hints / initial values |
| --- | --- | --- | --- | --- |
| Site password | `sitePassword` | password | Not marked | Enter new site passcode |



### Actions


| Control | Result | Component |
| --- | --- | --- |
| Edit password | Opens the `password modal` view. | `website-overview.tsx` |
| View website | No direct click handler; may be a menu trigger or linked control. See the sequence below. | `website-overview.tsx` |
| Launch | No direct click handler; may be a menu trigger or linked control. See the sequence below. | `website-overview.tsx` |
| Cancel | Closes or clears the `password modal` view/selection. | `website-overview.tsx` |
| Save Password | Updates local UI state; persistence is described separately below. | `website-overview.tsx` |


#### Linked navigation

| Link | Target in source |
| --- | --- |
| .eucodes.tech | `publicUrl` |
| View website | `publicUrl` |
| Launch | `/${slug}/website/theme` |



### Interaction sequence

Toggle password protection → Edit password → enter a passcode → Save Password. The local success state changes after a timer; View website opens the public URL.

### States and rules

Password protection and launch controls are not connected to persistence or public-site enforcement. The URL is hard-coded to the eucodes.tech domain pattern.

### Implementation references

Paths below are relative to the application repository. This is source-reviewed behavior, not a recorded browser test.

- `apps/web/src/app/sites/admin/[tenant]/website/page.tsx`
- `apps/web/src/features/website/website-overview.tsx`

Data and access helpers: `apps/web/src/lib/session.ts`, `apps/web/src/lib/server-api.ts`, `apps/web/src/lib/tenants.ts`

## Website overview

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/website`

### ഉദ്ദേശ്യവും പ്രവേശനവും

വെബ്സൈറ്റ് നിലയും പൊതു സൈറ്റിന്റെ ലിങ്കും പരിശോധിക്കുക.

Account sessionഉം തിരഞ്ഞെടുത്ത മഹല്ലിൽ resolved membership contextഉം വേണം; APIയിലെ നിലവിലെ platform elevation pathഉം ഇതിൽപ്പെടും. ഓരോ പ്രവർത്തനത്തിന്റെയും permissions/features API പ്രത്യേകം പരിശോധിക്കുന്നു.

പൊതു URL, വെബ്സൈറ്റ് സ്ഥിതി, password protection, View website, Launch എന്നിവ കാണിക്കുന്നു.

### പ്രവർത്തനക്രമം

Password protection മാറ്റുക → Edit password → passcode നൽകുക → Save Password. Timerനു ശേഷം local success മാറും; View website പൊതു URL തുറക്കും.
