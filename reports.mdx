## Finance reports

Host: `admin.<ROOT_DOMAIN>` · Route: `/[tenant]/finance/reports`

### Purpose and access

Browse the shared reports catalog and open a financial or tabular viewer.

You need an account session and a resolved membership context in the selected Mahallu (including the API’s current platform elevation path). The API independently checks the requested operation’s permissions and feature availability.

### Screen layout

The center contains category navigation, search, Quick Favorites, a report table, and an inline selected report. It receives accounts, collections, vouchers, categories, bank accounts, and overview data.

### Fields and displayed information


Displayed table columns: **Report Name & Details**, **Category**, **Engine**, **Action**.

### Interaction sequence

Search or choose a category → View/Open a report → review its generated rows → close to return. Star controls save favorites in browser localStorage for this tenant.

### States and rules

Catalog entries exceed the implemented backend reports. Some generated rows use approximations or fixed values. Favorites are browser-local; toolbar export/share and displayed date/basis controls must not be described as working backend filtering.

### പ്രവർത്തനക്രമം

തിരയുകയോ വിഭാഗം തിരഞ്ഞെടുക്കുകയോ ചെയ്യുക → View/Open വഴി റിപ്പോർട്ട് തുറക്കുക → വരികൾ പരിശോധിക്കുക → അടച്ച് മടങ്ങുക. Star ഉപയോഗിച്ച favorites ഈ മഹല്ലിന്റെ browser localStorageൽ സംരക്ഷിക്കുന്നു.

### നിലകളും നിയമങ്ങളും

പട്ടികയിലെ എല്ലാ റിപ്പോർട്ടുകൾക്കും പൂർണ്ണ backend implementation ഇല്ല. ചില വരികളിൽ അനുമാനമോ സ്ഥിരവിലയോ ഉപയോഗിക്കുന്നു. Favorites browserൽ മാത്രമാണ്; export/share അല്ലെങ്കിൽ date/basis നിയന്ത്രണങ്ങളെ പ്രവർത്തിക്കുന്ന backend filter ആയി വിവരിക്കരുത്.
